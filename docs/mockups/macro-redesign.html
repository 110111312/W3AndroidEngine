What A does now

  • Two tabs, one plan. BUILD holds the buildings and the researches in two rows of one sheet; UNITS holds what your halls train. The queue on the left is the same on both tabs, because the executor buys the lowest ready number across everything — a tab is a place to add, not a separate list.
  • One queue, numbered from 1. Base tickets first, army after, exactly the order the executor works in. A ticket with a long history behind it (the 21st unit) no longer reads like an array index.
  • The queue says what it will cost, at the bottom: gold and lumber for everything still on it.
  • A tally in the header — ready / waiting / stuck — so “why is nothing happening” is one look, not a scroll. Stuck rows still say why in words.
  • Every icon at least 44 dp, and the buttons are 44 dp circles with the count as a badge: the art says what the button is, the badge says how many tickets sit behind it.

Icons per race

  • Nothing is hard-coded: the panel asks the data for an icon, so each race gets its own art for free. The switcher above the phone shows it — Night Elf, Human, Orc, Undead.
  • Build button: the race's own build button (BTNHumanBuild, BTNNightElfBuild, BTNScourgeBuild). Orc has no build button in the archives this sketch was cut from, so it borrows the human one — in the game it will come from the same lookup as everything else.
  • Army button: the race's town hall (Town Hall, Great Hall, Necropolis, Tree of Life) — the building that makes the army. The alternative is a soldier's face (a Footman, a Grunt): reads as “units” more directly, but repeats the same photo on every mission.

Worth trying next (not built)

  1. Drag to reorder on a long press, with a gap where it will land. Better than seven taps to move a ticket from 9 to 2; riskier for a thumb that scrolls.
  2. A mini queue beside the buttons: the next 4 tickets as small icons above the arc, so you can see what is coming without opening anything.
  3. A pinned “now” row at the top of the queue for the ticket the executor is actually on, so the list cannot shift under your finger as tickets retire.
  4. A cost chip per row (195g 20l) instead of only the total.
  5. First-run hint: one line naming the gesture, shown until the first reorder.
