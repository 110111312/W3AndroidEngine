Macro panel — landscape sketch

Phone held sideways (844×390, the Realme's 19.5:9). Two plan buttons above the skill arc; each opens its sheet into the right-middle band: available above, your order below, both as icon grids now. The sheet never covers the stick, the skills, or the world where the hero stands.

Clickable — try the semantics

  • tap an available icon → a ticket enters the order at the end
  • tap a ticket → number drops, runs sooner; right-click → runs later
  • tap the − (top right) → removes it
  • shift-click a ticket → it finishes: disappears, your owned ×N rises, and when the last 0 is done the 1s become 0s

The spending rule, one sentence

Supply first, then the lowest number across both sheets — same-number items compete for the same gold. A greyed ticket (missing requirement, 🔒) never blocks anyone; an unaffordable one just waits, visibly.
